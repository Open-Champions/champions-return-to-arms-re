## The generator (`tools/remaster/tripo_gen.py`)

`TRIPO_KEY_FILE=<the owner's key file, see the credential index> python3 tools/remaster/tripo_gen.py balance` prints the
wallet; `... run local/remaster/tripo [--max 12] [armour sword ...]` prints the balance, runs each asset's steps (a
`text_to_model`, then for the armour `animate_rig` on that task), waits, downloads the PBR glb as
`<asset>.<step>.<type>.glb`, keeps `tasks.json` so a re-run resumes instead of paying twice, stops at the cap (12 tasks in
total, counted across runs) or at the first refusal, and prints the balance after. It sends text and task ids only; the key
is read from the file at run time and never printed or written. (python.org's Python on macOS has no CA roots: the system
bundle `/etc/ssl/cert.pem` is used.)

Tasks it would use: armour 2 (model + rig), sword 1, mace 1, arch 1, brazier 1, statue 1 = **7**, leaving 5 for
regenerations. Prompts (Read, not yet tried): every one names the style (dark-fantasy, weathered), "game-ready, clean
topology, PBR textures, no baked lighting", a face limit (armour 20,000, weapons 6,000, props 8,000-15,000), and a negative
prompt (helm, face, skin, base, baked shadows; for the brazier fire and glow). The armour is asked as **one set on a plain
mannequin in a T-pose** rather than four separate parts: separate generations do not share a body or a scale, and the rig
step needs a humanoid; the set is to be cut by its rig weights (below).

Cost to expect (Read, Tripo's published API pricing as known; to be checked on the platform before buying): a textured
text-to-model about 20-30 credits, PBR/detailed texture adds some, a rig about 25; the 7 tasks about 200-250 credits,
the full 12 under about 400.

## Plan for step 2 (when the assets exist)

- Files under `tools/godot/project/remaster/` when each is under 5 MB (tracked: they are ours), else `local/remaster/`
  until slimmed (`face_limit`, texture size).
- `er_layer.gd` outfit folders come from `RTA_ER_MODELS` / `local/souls-ref/er-models` only. Generalise: a list of outfit
  roots - `res://remaster` (source `remaster`, distributable) and the local Elden Ring root - each outfit tagged with its
  source; the Settings "Outfit" list gains "Remastered: <set>"; `er_fit.cfg [auto]` may name `remaster/knight`.
- The rigged glb's bones are Tripo's biped names (Mixamo-like: Hips, Spine, LeftArm, LeftForeArm, LeftUpLeg ...): a
  `[bones.remaster]` map in `er_joint_map.cfg` to the same regions the Elden Ring bones use, so `er_fit.gd` fits it
  unchanged. Parts by dominant weight: head -> HD (dropped as the helms are), spine/clavicle/upper arm -> BD,
  forearm/hand -> AM, legs -> LG; the mannequin's own body removed by material/colour (or asked away in a regeneration).
- Weapons: `remaster/weapons/<class>.glb` beside the Elden Ring ones (sword for the 1-hand-blade classes, mace for the
  blunt ones), grip found from the longest axis (pommel end) since generated weapons have no grip bone.
- Props: a turntable scene (`dev/remaster_preview.tscn`) only, placed nowhere in the game.
- Gate as rounds 4/5: `local/remaster/` sheets (hub, arachna1, islgoth; close and gameplay distance) beside the Elden
  Ring and the original figure, triangle/vertex/texture stats per glb, paced fps with and without.

## Recommendation

Top up the **API** wallet (not the web plan) with about 400 credits, run `tripo_gen.py run local/remaster/tripo --max 12`,
and judge the 7 results before any full set: a full set (7 class outfits, 9 weapons, a prop kit of ~20) is about 50-60
tasks, roughly 1,500-2,000 credits with one regeneration in three.
