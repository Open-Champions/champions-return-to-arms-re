# Native client work has moved

The shared C++/Godot client for Champions of Norrath and Champions: Return to Arms
now lives in [open-champions-godot](https://github.com/Open-Champions/open-champions-godot).

- [Both-game roadmap](https://github.com/Open-Champions/open-champions-godot/blob/main/docs/ROADMAP.md)
- [Preserved native-port assessment](https://github.com/Open-Champions/open-champions-godot/blob/main/docs/NATIVE_PORT.md)
- [C++ archive inspector and build instructions](https://github.com/Open-Champions/open-champions-godot/tree/main/native)

The inspector works; a playable native client remains future work. This repository
continues research on formats, simulation and online behavior used by those efforts.
See the [repository map](REPOSITORIES.md) for ownership.
