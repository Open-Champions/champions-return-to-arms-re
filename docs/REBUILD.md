# Source reconstruction has moved

The active Return to Arms C++ reconstruction, byte verifier, progress ledger and
contributor workflow now live in [champions-return-to-arms](https://github.com/Open-Champions/champions-return-to-arms).

Read its [rebuild guide](https://github.com/Open-Champions/champions-return-to-arms/blob/main/docs/REBUILD.md)
and run reconstruction commands from that checkout. This repository keeps research,
symbols, formats, Python analysis tools and patch evidence.

See the [repository map](REPOSITORIES.md) for both games and the shared Godot client.
